ZCode Pilot 使用说明
====================

一句话：ZCode 多账号切换器。保存多个 BigModel / z.ai 登录态，
一键切换，加密备份，换号不丢登录。


一、安装与启动
--------------
1. 双击 ZCodePilot-Setup-1.0.0.exe 安装；
   不想安装就双击 ZCodePilot-portable.exe。
   Windows 提示"未知发布者"时，点"更多信息"→"仍要运行"。
2. 启动后看到账号面板；关闭窗口会最小化到托盘，不会退出。


二、添加账号
------------
1. 点「添加账号」，会打开内置管理器。
2. 在管理器里选择 BigModel 或 z.ai，完成网页登录。
   · 添加新账号不会影响当前 ZCode 登录。
3. 登录完成后回到 ZCode Pilot，点「刷新」，账号会出现在列表。
4. 如果本机 ZCode 客户端已经登录，也可以点「捕获当前登录」直接收录。


三、切换账号
------------
· 在账号卡片点「切换到此账号」。
· 切换前会自动保存当前登录态，不会丢号。
· 如果 ZCode 正在运行，按提示重启 ZCode 生效。


四、额度说明
------------
· ZCode 软件本身免费，额度来自智谱账号。
· 新账号试用 5 天：
  GLM-5.3：300 万 tokens/天
  国内 BigModel 另有 GLM-5.3-Flash：500 万 tokens/天
· 试用结束后需要 GLM Coding Plan，或在 ZCode 里自备 API Key。
· 面板只对订阅账号显示套餐额度；
  试用/免费账号会标注「试用 / 免费账号 · 无 Coding Plan」，属正常现象。
· 活动领取请在内置管理器的「活动领取」中操作。


五、备份与迁移
--------------
· 导出全部：生成 .zsb 加密文件，需设置至少 6 位密码。
· 导入：选择 .zsb 文件并输入同一密码。
· 密码错误无法解密；忘记密码无法恢复，请自行保管。


六、数据与安全
--------------
· 账号数据保存在：C:\Users\你的用户名\.zcode-switch
· 所有数据只在本机，不上传服务器。
· 请只使用本人有权操作的账号。


七、常见问题
------------
Q：额度显示「无 Coding Plan」？
A：该账号没有订阅套餐，试用/免费号查不到套餐额度，不影响切换。

Q：切换后 ZCode 没变化？
A：按提示重启 ZCode；或确认 ZCode 安装路径设置正确。

Q：添加账号时网页登录失败？
A：检查网络能否访问 bigmodel.cn / z.ai，或换一个入口重试。

Q：杀毒软件报毒？
A：程序未购买商业代码签名证书，Electron 打包容易被误报；
   添加信任即可。

Q：如何卸载？
A：设置 → 应用 → ZCode Pilot → 卸载；
   如需清除数据，再删除 C:\Users\你的用户名\.zcode-switch。


八、说明
--------
本工具为本地账号管理面板，不提供账号或额度；
多号轮换存在风控/封号风险，请自行评估。
内置引擎基于 MIT 开源项目 Z·SWITCH (zcode-switch)，详见 NOTICE.md。
